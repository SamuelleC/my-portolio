UC Nexus

A room and schedule management system for the University of the Cordilleras, built as a web admin platform and a companion mobile app.

PHP MySQL JavaScript React Native Expo Thesis

Web admin

The staff-facing dashboard for campus rooms and schedules.

  • Campus summary and building overview
  • Room types, capacity, and schedule tools
  • Data upload to the mobile app
  • AI assistant for common admin questions

Mobile companion

An Expo / React Native app for building and checking class schedules on the go.

  • Personal class schedule view
  • Create schedule and overview actions
  • Home and calendar navigation

This page is a portfolio showcase only. The full web and mobile systems stay in their own repositories and are not bundled here.
